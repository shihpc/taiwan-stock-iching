#### 1.2.2 加權指數開盤價不可用（已實測）

**結論：大盤側不得採用「隔日開盤進場」。**

實測資料＝`taiwan-backtest/data/taiex_daily_agg.csv`，2005-01-03 ~ 2022-12-30，4,441 列
（4,440 組相鄰交易日），由本 session 直接計算：

| 量測 | 值 |
|---|---|
| `o0900` 與前一日 `c1330` **完全相等**的比例 | 4,439 / 4,440 ＝ 99.98% |
| 唯一例外 | 2005-09-19，跳空 −0.8437% |
| 隔夜跳空標準差 | 0.0127% |
| 當日開→收標準差 | 1.1384%（＝跳空的 **89.9 倍**）|

也就是說該欄的 `o0900` 實質是**前一日收盤的複寫**，不是 09:00 集合競價的真實開盤價。
拿它當進場價，等於用「當下已知的前一日收盤」成交，**憑空取得一段並不存在的報酬**。

**驗證範圍與限制**（CANON 第 4 條，不得略過）：
- **已驗證**：上表四個數字，對該 CSV 直接計算得出。
- **未驗證**：①該檔沒有 2023-01-01 之後的資料，近三年未查；②未以第二份資料源交叉比對；
  ③未確認成因——無法區分「指數本身就這樣發布」與「這份 CSV 的產製方式如此」。
  成因不同會影響「換一個資料源是否就有真開盤價」的答案。
- **不受影響**：個股有真實的 09:00 集合競價成交價，本條**只**約束大盤側。

## 3. 已知偏差（必須寫進報告）

- 上爻資料日**必然落後**其他五爻（美股收盤在台北凌晨），且窗長以**美股交易日**計。
- 集保為週頻、首筆 2026-08-07，無長歷史可回補。
- 事件層 `E` 的級距 5／10／15 未校準；`event_shadow_score` 為 shadow，**不影響正式卦象與排名**。
- 個股池與流動性門檻尚未定義，可能造成存活者偏誤。
- 大盤側**無可用開盤價**（§1.2.2），故大盤與個股的進場時點口徑一致採收盤；
  這排除了「開盤進場」這整類設計，是刻意的限制、不是疏漏。
- 除權息處理在 P1 規格中**完全未定義**；個股價格口徑（§1.2.1）目前只是提案。
