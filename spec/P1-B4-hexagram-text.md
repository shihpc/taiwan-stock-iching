## B4.1 文案組裝流程

輸入：`market_type`（stock／index）、`king_wen`(1–64)、六爻正式爻態（初→上 6 位元）、六爻分數、動爻集合、前卦紀錄、`horizon`、資料時間與品質旗標。

輸出順序固定〔v0.2 §6〕：**對象與期間 → 資料時間與品質 → 正式卦與維持天數 → 核心矛盾 → 真實形成路徑 → 主要支持及反對證據 → 待複核與失效條件 → 交易資格及事件**。先顯示摘要，逐爻與全部假設路徑收在展開區。

| 步驟 | 動作 | 產生方式 |
|---|---|---|
| S1 | 資料閘門：必要來源過期／缺值／不可比修訂 → 停止新結論，顯示最後有效卦與時間 | 規則〔§2.2、§1.3〕 |
| S2 | 由 6 位元反查 `king_wen`，載入靜態文本 | 規則〔補充〕 |
| S3 | 遲滯檢查：分數已過門檻但未達連續兩日 → **優先加註**「分數已變化，正式爻態仍維持前態」 | 規則〔§1.3〕 |
| S4 | 依 `market_type` 選 `stock`／`market` 欄位文字 | 靜態文本〔§1.2〕 |
| S5 | 形成路徑：比對保存紀錄，命中則套句型；無紀錄則**刪掉路徑句** | 規則＋靜態文本〔§2.1、§6〕 |
| S6 | 逐爻卡：靜態爻文＋即時原始值／單位／可用時間／覆蓋率／分數／前態 | 規則注入〔§1.2〕 |
| S7 | 失效區：四層失效依觸發條件展開（B4.4） | 規則＋靜態文本〔§2.2〕 |
| S8 | 交易資格與事件：`event_shadow_score` 平行顯示，**不改正式卦／排名／動爻** | 規則〔§7〕 |

**可用句型（逐字採用）**〔§6〕：

> 「截至〔時間〕，〔期間〕為〔卦名〕。目前〔A〕支持而〔B〕尚未確認，重點是〔研究問題〕。本次由〔前卦〕的〔爻〕確認〔變化〕形成。若〔具體已登錄條件〕成立，則〔原判斷〕需改寫。」

**AI 生成範圍**：v0.2 全文未授權任何 AI 生成文案。**第一版一律不使用 AI 生成敘事**〔補充〕；所有句子必須來自靜態文本或規則填空。理由：§6 明定「真實前態未知時刪掉路徑句，不能補故事」，AI 續寫必然違反此條。

**紅線**〔§6〕：模型效果未驗證時顯示「狀態解讀／效果未證」，不顯示候選名單、不把分數寫成勝率；持有期入口不是建議必須持有的日數。對應本專案回測政策：**波段與中期第一版只展示現況卦象與六爻依據**。

## B4.3 形成路徑的資料需求

必須保存〔§2.1〕：前卦、現卦、前後六爻分數、正式翻爻日期、變動爻集合、維持交易日數、資料版本、模型版本、原因類別（至少區分「新增市場資料」／「歷史資料更正」／「模型版本改變」）。**每個 `horizon` 各存一份（**鍵須含 `market` 與 `stock_id`**，見 `P1-B5-dimensions.md` §B5.2；R5g 補）**〔§1.3〕。

| 情境 | 頁面呈現 |
|---|---|
| 單爻形成、有紀錄 | 套路徑句，只顯示命中那一列；其餘五爻須標明不變 |
| 多爻同時形成 | 一次列出**全部**實際改變的爻；**不得編造中間卦或先後次序** |
| 同卦持續 | 顯示維持天數＋連續分數走勢＋子指標分歧；維持天數只描述穩定性，**不提供延續機率** |
| 資料修訂換卦 | 標「重算差異」，**不可描述成市場當日轉折** |
| 無歷史紀錄 | 標「假設路徑」 |

**「假設路徑不得冒充歷史」的具體呈現**〔補充，落實 §2.1／§6〕：

1. 摘要區**刪除**路徑句，不留佔位文字。
2. 六列前卦表只出現在**預設收合**的展開區，表頭沿用 v0.2 原句「下表是結構上可能的單爻前卦，不是已發生的歷史」。
3. 假設路徑列**不得**帶日期、不得帶「剛失去／剛獲得」以外的時間副詞、不得進入分享卡與摘要文字。
4. 欄位層級硬性區隔：`formation.observed`（含 `flip_date`）與 `formation.hypothetical`（**無** `flip_date` 欄位）為兩個不同鍵，渲染端不共用元件。

## B4.4 四種失效的觸發與呈現

| 層次 | 觸發〔§2.2〕 | 頁面呈現 | 對應本專案規則 |
|---|---|---|---|
| 敘事待複核 | 主要支持分下降或反對證據增加，**尚未正式翻爻** | 保留正式卦；文案確定性降級並列原因；掛「分數已變化，正式爻態仍維持前態」 | 遲滯期（過門檻但未連兩日）。**分數轉弱與正式翻爻分開標示** |
| 結構解釋失效 | 關鍵爻**正式**翻轉 | 重寫核心矛盾；**不以卦名判更好或更差** | 完成遲滯確認後換卦；各 horizon 獨立 |
| 交易資格失效 | 已確認限制依**生效時間**適用於該方向／策略 | 更新資格與風險；**不必等待翻爻**，**不一律推定全部交易禁止** | 走 S1 §A5：限制只影響適用方向；解除不自動恢復推薦 |
| 資料解釋失效 | 必要來源過期、缺值、不可比修訂 | **停止新結論**，保留最後有效結果並顯示日期 | S1 資料閘門；缺資料不補陰、不累加確認天數 |

共同註記〔§2.2〕：本層失效是**分析命題失效**，不產生統一賣出價；停損、部位與最大損失屬策略規格，須另行驗證。

## B4.5 個股與大盤的語意分離

**實作規定**〔補充，落實 §1.2／§3.3〕：靜態文本每個爻位、每條路徑、每條失效條件都存 `stock` 與 `market` **兩個獨立字串**；渲染函式簽章必須帶 `market_type`，**不得提供 fallback**——缺哪一側即為資料錯誤，測試須擋下。**禁止「共用文案＋替換名詞」的實作。**

| # | 爻位 | 個股語意 | 大盤語意 | 容易誤用之處 |
|---|---|---|---|---|
| 1 | 二爻 | 價格趨勢（絕對方向） | 市場廣度（參與家數） | 把大盤二爻寫成「價格趨勢有支持」。絕對方向與參與家數是不同證據 |
| 2 | 四爻 | 量價確認 | 現貨資金（法人流向） | 用「法人買超」描述個股四爻——個股法人在**五爻**；價量情境與法人資金不可互相代稱 |
| 3 | 五爻 | 籌碼供需 | 衍生品支持 | 把基差／VIX／P/C 寫進個股五爻；且 **P/C 第一版不計分**，只顯示 |
| 4 | 上爻 | 外部支持（須拆市場／產業） | 海外與外部（須標海外交易日與可用時間） | 兩側共用「大環境轉好」籠統句 |
| 5 | 初爻 | 營運基礎（**有公布延遲**） | 指數趨勢（無公布延遲） | 共用同一組「資料延遲」註記；且指數趨勢不等於個股普遍上行 |

交叉閱讀（大盤初↔個股二、大盤二↔個股三、大盤四↔個股五）**是解釋關係，不是新增加分**；個股上爻已含市場因素〔§3.3〕。

## B4.6 三期間衝突的頁面規則

依據〔§2.1〕：「三期間衝突：各自陳述其視窗證據。短線改善而中期未確認，可提出修復假說；不能直接叫作趨勢反轉。」

| 規則 | 內容 |
|---|---|
| R1 | 三期間**各自獨立區塊**，各有自己的卦、爻態、動爻、維持天數、形成路徑〔§1.3〕 |
| R2 | 期間卦不同時，頁面**不合成單一結論**、不加權平均、不排吉凶 |
| R3 | 短線改善而中期未確認 → 標「修復假說（待確認）」；**禁止**出現「趨勢反轉」字樣 |
| R4 | 短線翻爻**不得**寫入中期的動爻與形成路徑 |
| R5 | 依回測政策：波段與中期標「證據不足」，只展示現況卦象與六爻依據，**不輸出方向分數與候選名單**；短線未通過門檻時同樣掛「效果未證」 |
| R6 | 期間衝突時顯示中性提示語，例如「三期間證據不一致，請分別閱讀各期間視窗」〔補充〕 |
